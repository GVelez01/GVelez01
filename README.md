# Gio Velez

Digital marketing lead at Partner In Publishing. I run web delivery for education publishers and build the tools my team works in: client websites, internal apps and Claude Code mods. Product manager by training, builder by habit.

## What I build

- **Client websites.** Static Astro sites on one shared starter: AVIF images, variable fonts, JSON-LD, `llms.txt`, a gated GitHub Actions deploy with visual diffs, and an optional self-edit admin so clients change their own copy without a CMS.
- **Team tools.** A priority queue that replaces Slack DMs for dev and video requests. PMs file a request, the owner ranks it, and the page works out the delivery week. Grist plus a static widget, no build step.
- **Claude Code mods.** An hours band above the prompt that reads my calendar and time tracker and shows what is left to log this week.
- **AI pipelines.** Narrated product walkthrough videos cut from real app footage, and multi-lane site audits (design, copy, SEO, accessibility, performance) that ship as hosted reports.
